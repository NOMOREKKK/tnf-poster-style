# 版式原型（Layout Archetypes）

生成海报时先选定一个原型，再填内容。原型决定构图，不允许自由发挥成「随机海报」。

画幅默认 **1080 × 1440**。标注百分比相对画幅。

---

## A. 主视觉页（Hero Plate）— 默认首选

适用：单主题海报、封面、社交媒体主图。

```
┌────────────────────────────┐
│ LOGO 眉标              6%  │
│                            │
│      ┌──────────────┐      │
│      │              │      │
│      │   器皿主插画  │ 42%  │  居中，宽 78%
│      │  (盘装世界)   │      │
│      │              │      │
│      └──────────────┘      │
│                            │
│  TITLE ENGLISH        10%  │  左对齐，72–96px
│  副标中文两行              │  28–36px
│                            │
│  ┌────────────────────┐    │
│  │ 正文 3–5 行小字     │ 12% │  右侧缩进栏宽 52%
│  │ reference: …       │    │
│  └────────────────────┘    │
│                     8%     │
└────────────────────────────┘
```

- 背景：`#EEEDD9` 或主题对应色
- 图文关系：图上文下，标题是视觉第二锤

---

## B. 图文对开（Split Spread）— 信息量大时

适用：有较长正文、数据引用、需要左右平衡。

```
┌────────────────────────────┐
│ LOGO                  眉标 │
│ ┌──────────┐  ┌──────────┐ │
│ │          │  │ TITLE    │ │
│ │  器皿    │  │ 副标     │ │
│ │  插画    │  │          │ │
│ │  52%宽   │  │ 正文栏   │ │
│ │          │  │ 40%宽    │ │
│ │          │  │ reference│ │
│ └──────────┘  └──────────┘ │
└────────────────────────────┘
```

- 左图右文 **或** 右图左文（有视线引导时跟着看）
- 文栏顶端与插画视觉重心对齐，不要齐顶硬排

---

## C. 上下双篇（Magazine Duo）— 一页两个子题

适用：对比两件事（肉 vs 海鲜）或系列连页。

```
┌────────────────────────────┐
│ 背景色 A · 子题一          │  上 50%
│  TITLE_1   + 小插画 + 正文 │
├────────────────────────────┤
│ 背景色 B · 子题二          │  下 50%
│  小插画 + TITLE_2 + 正文   │
└────────────────────────────┘
```

- 上下用**两个不同背景色**横切
- 上下镜像构图（图左右交替），避免死板对齐
- 每半页仍保持「巨大标题 + 细小正文」对比

---

## D. 图解数据页（Infographic Panel）— 有数字时

适用：碳足迹、比例、流量等需要示意数据。

```
┌────────────────────────────┐
│  TITLE 巨大                 │
│  副标                        │
│  ┌──────────────────────┐   │
│  │  器皿/场景 + 粗箭头   │   │
│  │  + 白底数字标签框     │   │
│  └──────────────────────┘   │
│  说明小字 + source          │
└────────────────────────────┘
```

- 数字标签：白底黑框圆角矩形，数字用鲑鱼橙 `#DC976B` 或墨黑
- 箭头：粗黑线描边 + 平涂橙/灰填充，风格同插画
- 场景仍保持平涂勾线，箭头是同一支笔画的

---

## E. 全幅隐喻（Full-bleed Metaphor）— 海报冲击

适用：纯视觉海报、展览、单句主张。

```
┌────────────────────────────┐
│         眉标               │
│                            │
│    器皿插画铺满 70% 高     │
│    (可压出画面外)          │
│                            │
│         TITLE              │
│         一句副标           │
└────────────────────────────┘
```

- 插画可裁切出血，盘子边缘压到画布外
- 正文可省略，最多 2 行

---

## 选型决策

| 用户要什么 | 原型 |
|---|---|
| 普通主题海报 / 照片转海报 | **A** |
| 文案长、有参考文献 | **B** |
| 两个对比主题 | **C** |
| 强调数字/比例 | **D** |
| 只要一句主张、要冲击力 | **E** |
| 没说清 | 默认 **A**，并在交付时告知可换 B/C/D/E |
