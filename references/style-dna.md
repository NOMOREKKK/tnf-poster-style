# TNF「LOW CARBON EATING」插画风格 DNA

来源：The North Face 日本线环保内容系列（BranD 杂志转载页）。
本文件是画风锁死规范。生成任何同风格物料前先读本文件，所有数值、色值、构图规则以本文为准。

---

## 1. 风格定位

| 维度 | 判定 |
|---|---|
| 画种 | 平面编辑插画 / 教育图解风 |
| 血统 | 日本成人大人向绘图本 × 瑞士编辑排版 |
| 笔触 | 马克笔勾线 + 平涂填色 |
| 质感 | 零质感。不要颗粒、不要纸纹、不要噪点 |
| 情绪 | 温和、聪明、有点幽默，不恐吓说教 |

一句话锚点：
> **粗黑线平涂涂鸦 + 餐具盛放世界 + 冷静编辑排版**

---

## 2. 插画技法（必须同时满足）

### 2.1 线条
- 纯黑近黑：`#1A1A1A`
- 线宽均匀，1080px 画布上约 **4–6px**（感觉像 2 号马克笔）
- 端点圆润，转角略圆，允许轻微手绘抖动但整体受控
- **闭合轮廓**。所有色块由黑线包住
- 禁止：排线、交叉线、毛笔飞白、线宽变化（书法笔锋）

### 2.2 填色
- **纯平涂**，零渐变、零阴影、零高光渐层
- 器皿（盘/碗）可用纯白 `#FBFBF7` + 一条内侧弧线暗示厚度
- 同一物体不超过 2 个色阶（本色 + 一个暗部可选，暗部也是平涂）

### 2.3 造型语言
- 略俯视 / 微等距混合，**不用透视网格**
- 形状概括：山是三角，树是圆团/水滴/针叶三角，云是拉长圆角条
- 比例夸张：食物=风景容器，人是小小的比例尺

## 3. 母题系统（系列最强识别点）

核心视觉玩笑：**日常餐具里装着整个世界**。

| 器皿 | 里面装什么 | 隐喻 |
|---|---|---|
| 白圆盘 | 山脉+森林+河流+农田 | 餐桌连着户外 |
| 白深碗 | 海洋+鱼+珊瑚+钓鱼的人 | 海鲜盘=海洋本身 |
| 白圆盘 | 土层蛋糕切片+树 | 土壤=可食用的层次 |
| 白圆盘 | 奶牛+干草捆+玉米 | 肉=一整套农牧系统 |
| 白圆盘 | 丢弃的食物+渔获+举盘子的人 | 浪费=倒在盘外的损失 |

生成海报时：
1. 先定「一只器皿 + 一个世界」的主隐喻
2. 一图只讲一个玩笑，禁止并列多个隐喻
3. 器皿必须是白色厚边圆盘/圆碗，黑线勾边

## 4. 色板（取自原稿采样，直接用）

### 4.1 背景（纸面感，一组轮换）
| 名称 | HEX | 用法 |
|---|---|---|
| 奶油鼠尾草 | `#EEEDD9` | 首选，封面/主视觉 |
| 蜜桃灰粉 | `#EED4C5` | 肉类/食物主题 |

### 4.2 插画平涂色
| 角色 | HEX |
|---|---|
| 墨线 / 标题 | `#1A1A1A` |
| 器皿白 / 衣物白 | `#FBFBF7` |
| 森林绿 | `#5B795D` |
| 浅草绿 | `#ADC3AA` |
| 橄榄苔绿 | `#8E8155` |
| 青灰绿 | `#649193` |
| 深海蓝 | `#2B4353` |
| 浅天蓝 | `#CDDFEB` |
| 鲑鱼橙 | `#DC976B` |
| 芥末黄 | `#D9DF7E` |
| 土棕 | `#938056` |
| 牛奶粉 | `#F0C4B8` |
| 胡萝卜橙 | `#E87A3D` |

### 4.3 用色纪律
- 一版背景 **只用 1 个** 4.1 色
- 插画内彩色 **不超过 6 种**（不含黑白）
- 大面积低饱和，小面积点睛高饱和（橙/黄）
- 禁止：霓虹、纯红纯蓝大色块、CMYK 印刷四色感

## 5. 人物规范

| 项 | 规则 |
|---|---|
| 头身比 | 1:5.5 – 1:6.5（偏小巧，非写实） |
| 脸 | 两点眼 `#1A1A1A`，可选一条微笑弧线；无鼻无耳或极简 |
| 发 | 实心色块，可带 2–3 根呆毛 |
| 衣 | 工装/户外休闲：棒球帽、白T、卡其裤、平底鞋 |
| 色 | 衣白 `#FBFBF7`，裤橄榄 `#8E8155`/`#938056`，帽可蓝 `#2B4353` |
| 动态 | 静：站、坐盘沿、垂钓、端盘。禁止奔跑/战斗/夸张透视 |
| 尺寸 | 人物高度 ≤ 插画区高度的 1/3，是比例尺不是主角 |

## 6. 版式系统

### 6.1 画幅
- 主输出：**1080 × 1440（3:4 竖版）** 或 1080 × 1350
- 也可按「杂志对页」做 2160 × 1440

### 6.2 栅格
- 外边距：左右 8–10% 画幅宽，上 6–8%，下 8%
- 双栏：图 55% / 文 40%（或对调），中缝 5%
- 半版分隔：上下两篇时，色块满幅横切

### 6.3 字体层级（严格）
| 层 | 字 | 尺寸（1080 宽基准） | 处理 |
|---|---|---|---|
| 系列眉标 | Helvetica/Arial Bold | 14–16px | ALL CAPS，字距 +0.2em，居中或左 |
| 英文大标题 | Helvetica Neue Bold / Arial Black | **72–96px** | ALL CAPS，行高 0.95，紧排，纯黑 |
| 日文/中文副标 | Noto Sans JP Bold / 思源黑体 Bold | 28–36px | 行高 1.45，最多 2 行 |
| 正文 | Noto Sans JP Regular / 思源黑体 | 15–17px | 行高 1.75，段距 1.2em |
| 参考/脚注 | 同正文 | 12–13px | 可带下划线链接感 |

层级对比是版面签名：**巨大标题紧挨细小正文**，中间不要过渡字级。

### 6.4 版面骨架（杂志页）
```
┌─────────────────────────┐
│ [LOGO]     SERIES LABEL  │  ← 页眉细条
│                         │
│    ┌─────────────┐      │
│    │  主插画      │      │  ← 器皿隐喻，占 45–55%
│    │  (餐具世界)  │      │
│    └─────────────┘      │
│                         │
│  BIG TITLE              │  ← 英文大标题左对齐
│  副标两行               │
│                         │
│  正文小字栏……           │  ← 右侧或下方
│  reference: xxx         │
└─────────────────────────┘
```

### 6.5 装饰
- 只有：品牌 logo、系列眉标、细分隔线、下划线链接
- 禁止：几何装饰、渐变条、阴影、圆角色块按钮

---

## 7. 文案调性

- **英文标题**：短促、全大写、陈述句（LOW CARBON EATING / MEAT / SEAFOOD / PLANTS）
- **副标**：一个反问或一个诗意陈述，两行内收束
- **正文**：事实+数据+温和倡议。先给现象，再给数字，最后给「我们可以怎样」
- **语气**：冷静、可信、不焦虑。像聪明朋友聊天，不像公益广告训话
- **参考**：文末 `reference:` + 可核验来源，强化编辑可信度

---

## 8. 反模式（出现即风格崩坏）

1. 渐变、投影、发光、玻璃拟态、3D 渲染
2. 厚涂笔触、油画质感、水彩晕染
3. 霓虹色、高饱和对比色块
4. 写实人体、肌肉结构、动态打斗
5. 一图塞多个隐喻、满构图无留白
6. 字级连续过渡（大标题→中标题→小标题齐全）
7. 装饰性图形元素（花纹、几何点缀、图标堆砌）
8. 恐惧诉求画面（灾难、骷髅、警告三角）

## 9. 自检清单（出图前逐条打勾）

- [ ] 黑线是否均匀粗、圆角端点、闭合？
- [ ] 是否纯平涂、零渐变零阴影？
- [ ] 是否只有 1 个背景色？插画彩色 ≤ 6？
- [ ] 是否有「器皿装世界」主隐喻？且只讲一个？
- [ ] 人物是否小、简脸、静姿态？
- [ ] 标题是否巨大 ALL CAPS + 正文细小，中间无过渡字级？
- [ ] 文案是否冷静事实向、不恐吓？
- [ ] 整页是否大量留白、外边距 ≥ 8%？
